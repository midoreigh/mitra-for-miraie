# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
which applies to all project spaces: issues, pull requests, discussions and any other
communication about the project.

In short: be welcoming and respectful, give and accept constructive feedback gracefully, focus
on what's best for the community, and don't harass, insult or demean anyone.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainer at
midoreigh@gmail.com. Reports are handled promptly and in confidence. The maintainer may remove
comments, commits or other contributions, or ban contributors, for behaviour that breaks this
code, following the Contributor Covenant's enforcement guidelines.
